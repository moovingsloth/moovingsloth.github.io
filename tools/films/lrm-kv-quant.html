Reasoning LLMs  KV cache during decoding
Reasoning models write a long chain of thought before they answer.Every generated token adds keys and values to the KV cache.
The problem  memory grows with the reasoning itself
device memory
The cache grows token by token, for as long as the model thinks.It limits how long a model can reason and whether it fits on a small device.
Quantization  fewer bits per stored key and value
−47.5 pt

Accuracy gap versus FP16 in my first attempt, a modified ThinKV implementation. AIME 2025 subset, 10 problems × 4 responses, DeepSeek-R1-Distill-Qwen-14B.

Quantizing every token the same way broke the reasoning.Small errors build up along the chain, and one wrong step changes the final answer.
